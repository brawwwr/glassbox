# Bought the 2 TB NVMe

Ordered a 2 TB NVMe, same model line as the existing 1 TB, PCIe 4.0. Paid $149 on sale.
Reason: the 1 TB was down to 50 GB free and I want somewhere for VMs, Docker images and model files
that is not the Windows drive.

Plan: install in the second M.2 slot, format as F:, move Steam library and the WSL disk there.
Note to self: the second M.2 slot shares bandwidth with SATA ports 5-6 on this board. I do not use
those ports, so fine.

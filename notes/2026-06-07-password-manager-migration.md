# Moving to a new password manager

Exported from the old manager as CSV, imported into the new one, then deleted the CSV with a secure delete
and emptied the trash. Checked that the CSV was not in any cloud-synced folder first. It was in Downloads,
which is not synced. Good.

Turned on the new manager's breach monitoring. Twelve entries flagged as reused; rotated the five that
matter (email, bank, cloud, GitHub, domain registrar). The rest are forum accounts from 2011.

Set up the emergency access contact.

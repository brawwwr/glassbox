# WSL2 tips I keep re-learning

- .wslconfig lives in the Windows user profile, not in Linux. It must be named exactly that, no .txt.
- WSL defaults to half the RAM. Set memory= explicitly.
- Work in /home, not /mnt/c. File I/O across the boundary is slow.
- Windows programs run from Linux with .exe: wsl.exe --shutdown, ollama.exe list.
- After changing .wslconfig: wsl --shutdown, wait ten seconds, reopen.
- Docker Desktop with the WSL2 backend shares the .wslconfig memory limit; its own slider is disabled.
